RECOVERABLE SOUNDING

一个由飞行器、飞控、无线通信、地面站和业务终端组成的高空探测系统。A high-altitude sounding system combining the aircraft, flight control, radio link, ground station and operational terminal.

SYSTEM / ARCHITECTURE

系统由通信、飞行器（包含探空装置）、地面站和业务计算终端组成。装置由标准 750 g 高空气球搭载升空，飞行器达到约 30,000 m 后与气球分离，并以变斜翼无动力滑翔实现远程精确回收。

研究内容覆盖气动布局、参数化建模、CFD 仿真、六层 PCB、MBD 飞控、UHF / LoRa 通信、极端环境制造和业务计算。

The system combines communications, a flight vehicle with the sounding payload, a ground station and an operational terminal. A standard 750 g balloon lifts the system to approximately 30,000 m, where the aircraft separates and returns through an unpowered morphing-wing glide.

The work covers aerodynamic configuration, parametric modeling, CFD, a six-layer PCB, MBD flight control, UHF / LoRa communications, extreme-environment manufacturing and operational computation.

ENGINEERING LAYERS

气动布局 / Aerodynamics

变斜翼融合弹翼布局，针对高空复杂气流和远距离无动力滑翔进行设计。

建模与仿真 / Simulation

SolidWorks、XFlow、XFLR5、ANSYS-Fluent / STAR-CCM+ 参与迭代。

飞控 / Flight control

MBD、自整定 PID 与总能量管理策略，处理分离后的非线性扰动。

通信 / Communications

UHF、LoRa CSS 与高增益八木天线组成低功率双向链路。

制造 / Manufacturing

PMI 泡沫、HT-PLA-GF、PA11 与密封结构服务于高空环境。

业务终端 / Terminal

MAVLink 地面站与 ISA 业务计算终端构成地面侧。
