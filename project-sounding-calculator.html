项目说明Project notes

这是一个纯前端、单文件、响应式的高空探空业务模拟计算网页，使用 React 与 Tailwind 实现。它将 ISA 对流层与平流层模型、达因公式（WMO 推荐业务标定，二分法求解）、理想气体方程和气体比举力计算组合起来，实时估算任意高度的温度、气压、密度、气球地面充气体积、实际净举力、内外压差和爆炸高度。

工具支持高精度气球克重、载荷、升速、气体类型与纯度、温度和压力等输入，可以通过滑块和键盘双向修改，并用 SVG 显示放飞、穿越对流层顶和爆炸节点。预警模块对体积膨胀余量、低温脆性、卡门涡街、积冰和气体纯度安全做基础提示，结果仅供方案参考。

This is a single-file, responsive front-end application built with React and Tailwind. It combines ISA tropospheric and stratospheric models, the WMO-recommended Dines formula solved by bisection, the ideal gas law and gas buoyancy to estimate temperature, pressure, density, launch volume, net lift, pressure difference and burst altitude.

Inputs include balloon mass, payload, ascent rate, gas type and purity, temperature and pressure. Sliders and keyboard input are supported, with SVG visualization for launch, tropopause and burst nodes. Basic warnings cover expansion margin, low-temperature brittleness, vortex shedding, icing and gas-purity safety. Results are intended for planning reference only.

为什么做它Why it exists

公开的气象气球计算工具往往是静态查算表，或者能输入和输出的变量很少。这个小工具尝试把更多变量放进同一条实时求解链路里，让放飞前的估算、复核与记录更直观。

Many public balloon calculators are either static lookup tables or expose only a small number of variables. This project experiments with a single real-time solving loop that makes pre-launch estimation, review and record keeping more direct.
